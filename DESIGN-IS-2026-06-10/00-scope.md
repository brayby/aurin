# Scope

**Audited:** Aurín — React Native (Expo SDK 56, expo-router native tabs) tarot reflection app.
Screens: Today (`src/app/index.tsx`), Read (`src/app/read.tsx`), Cards (`src/app/cards.tsx`), Settings (`src/app/settings.tsx`), Explore (`src/app/explore.tsx`, orphaned template), shell (`src/app/_layout.tsx`, `src/components/app-tabs.tsx`, `src/components/screen.tsx`), tokens (`src/constants/theme.ts`).

**Primary user:** Tarot practitioner with a physical deck seeking daily reflection and spread interpretation help.

**Primary task:** Draw with physical deck → log/read a spread with Aurín's guidance. Secondary: daily card reflection, 78-card reference.

**Constraints:** Light-mode-only v1 (documented in theme.ts:2-5). Expo v56. Brand: warm, candlelight-and-aged-paper.

**References:** Wildling Skincare (Behance — page fetch returned no visual content; direction taken as natural-minimal skincare aesthetic), La Plage by Studio Born (terracotta-dominant, gold accents, warm wood, bold-but-refined type, 60s–70s beach nostalgia, "seaside elegance").

**Goal stated by user:** modern, minimalist, elegant design language.
